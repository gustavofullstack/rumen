RUMEN

O navegador escrito em Rust.
Seu, livre e privado.

Motor próprio sobre componentes Rust (layout, CSS, GPU, rede). Você escolhe: navegação normal, privada ou anônima pelo Tor, com acesso Web3 nativo.

⬇ Baixar para Linux
curl -fsSL https://gustavofullstack.github.io/rumen/install.sh | sh

Linux x86_64 · CachyOS, Arch, Ubuntu, Fedora · verificação SHA-256 automática

Motor em Rust

Sem C++ no caminho de layout, estilo e renderização. Segurança de memória por padrão.

Navegação privada

Ctrl+Shift+N: perfil temporário em memória, apagado ao fechar. Nada fica no disco.

Modo Tor 🧅

Ctrl+Shift+O: todo o tráfego pela rede Tor, com acesso a sites .onion. Se o Tor cair, o RUMEN bloqueia a rede para não vazar seu IP.

Web3 nativo

Abra ipfs://, ipns:// e domínios .eth direto na barra de endereço.

Você decide os dados

Modo normal guarda cookies, cache e sessão localmente. Os modos privado e Tor não guardam nada.
